================================================================================
REDIS CACHE - QUICK START GUIDE
================================================================================

1. VERIFICAR INSTALAÇÃO

   # Verificar se Redis está instalado e rodando
   redis-cli ping
   # Resposta esperada: PONG

   # Se Redis não está instalado:
   # Windows: Usar WSL2 ou Docker
   # docker run -d -p 6379:6379 redis:latest

2. CONFIGURAR

   # .env já está atualizado com:
   CACHE_STORE=redis
   REDIS_HOST=127.0.0.1
   REDIS_PASSWORD=null
   REDIS_PORT=6379

   # Para desenvolvimento (sem Redis):
   CACHE_STORE=database

   # Para produção (Railway + Redis):
   CACHE_STORE=redis
   REDIS_HOST=seu-railway-redis-host
   REDIS_PASSWORD=sua-senha

3. EXECUTAR TESTES

   php artisan test tests/Feature/CachingIntegrationTest.php

   # Testes esperados:
   # - test_alertas_service_uses_cache PASSED
   # - test_graph_cache_for_single_pool PASSED
   # - test_pool_data_cache PASSED
   # - test_cache_invalidation_on_daily_record_create PASSED
   # - test_cache_pattern_invalidation PASSED

4. MONITORAR CACHE (DEV)

   # Terminal 1: Abrir Redis CLI
   redis-cli

   # Dentro do redis-cli:
   KEYS cache_*              # Ver todas as chaves
   GET cache_alertas_5       # Ver valor específico
   TTL cache_graph_1_abc123  # Ver tempo de vida restante
   FLUSHDB                   # Limpar todo o cache (⚠️ só dev!)
   DBSIZE                    # Número total de chaves

5. DEBUG EM ARTISAN TINKER

   php artisan tinker

   >>> Cache::get('cache_alertas_5')           # Ver um alerta
   >>> Cache::forget('cache_alertas_5')        # Remover um alerta
   >>> Cache::flush()                          # Limpar tudo
   >>> Cache::all()                            # Ver todas as chaves
   >>> config('cache.default')                 # Ver driver ativo

6. PERFORMANCE ESPERADA

   Sem cache:
   - Dashboard carregamento: ~450ms
   - AlertasService::calcular(): ~150ms
   - CloroPhChartWidget::getGraficos(): ~300ms

   Com cache (hit):
   - Dashboard carregamento: ~35ms (13x mais rápido)
   - AlertasService: ~5ms (30x)
   - CloroPhChartWidget: ~10ms (30x)

7. INVALIDAÇÃO AUTOMÁTICA

   O cache é automaticamente invalidado quando:
   - Novo DailyRecord é criado/editado
     → Invalida gráficos, alertas, painel

   - Stock muda
     → Invalida alertas, painel

   - Incidente é criado/resolvido
     → Invalida alertas

8. TROUBLESHOOTING

   Problema: "Redis connection refused"
   Solução: Verificar se redis-cli ping retorna PONG

   Problema: "Cache não atualiza"
   Solução: Aguardar TTL expirar ou rodar Cache::flush()

   Problema: "Memory leak Redis"
   Solução: Ver redis-cli INFO memory, cache com TTL expira automaticamente
